# TDD工程別コンテキスト

TDDの入口はリポジトリ内の `.agents/skills/document-as-data-tdd/SKILL.md` とする。
このファイルは旧指示からの参照先として残す索引であり、全工程の指示を常時読み込ませるものではない。

進行役は `tdd-context/run.md`、各担当は `tdd-context/common.md` と自分の工程の文書だけを読む。

## 工程文書

* Red: `tdd-context/red.md`
* Green: `tdd-context/green.md`
* Refactor: `tdd-context/refactor.md`
* 新しい主チャットからの開始文: `tdd-context/start.md`

既存の安全・Git・レビュー規則は `AGENTS.md` と `common.md` に従う。
