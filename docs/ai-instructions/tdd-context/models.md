# モデル選択の開始方針

これは工程規則ではない。起動時に利用可能なモデルと推論設定を確認し、
モデル名を工程文書へ固定しない。費用や利用枠も確認せずに断定しない。

* Luna：定型テスト、明確な通常Green、局所的な重複除去・命名・可読性の整理。
* Sol：新しいAPI・外部契約、call siteの意味判断、通常の構造的Refactor、責務・依存関係の判断。
* Astra：問題・主要制約・観測事実が揃い、Solで扱い切れない広範囲かつ多制約の問題のみ候補。「重要」「上流」「原因不明」だけでは選ばない。

情報不足は先に資料取得で解消する。工程名だけでモデルを固定せず、
開始時に決めたモデルを工程中に細かく交代させない。
高額設定はユーザーの承認済み範囲を超えて使わない。
選択理由や価格比較の長い議論を担当工程へ渡さない。
