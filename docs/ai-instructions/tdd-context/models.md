# モデル選択の開始方針

共通TDDの参照版。正本は `codex-workflows/skills/tdd-workflow/references/models.md`。

進行役は担当を起動する前に読む。サブエージェントへの委任は、利用環境で委任機能を使える統括モデルから、起動可能と確認できたモデルへだけ行う。モデル名や系列だけで対応可否を決めず、実在する委任ツールの対応モデルID、推論設定、指定権限を確認する。

| 担当 | モデル・推論レベル |
| --- | --- |
| Red | 統括と同じモデルID・推論レベル |
| Green | 契約が明確な通常実装は、起動可能なLuna系を第一候補とする。利用できなければ、起動可能な候補の中から作業に適したモデルを選ぶ。推論レベルはユーザー指定と利用環境の制約に従う |
| Refactor | 統括と同じモデルID・推論レベル |

Red・Refactorは統括の実際の設定を確認し、別コンテキストへ同じ設定を明示する。指定を省略する場合は両方を継承するツール仕様を確認する。統括の設定が不明、または同じ設定で起動できない場合は報告し、黙って別モデル・別推論レベルへ変更しない。統括が工程を兼任することで代用しない。

ユーザーの明示指定を優先するが、利用できないモデルを指定された場合はその制約を報告する。費用や利用枠を未確認のまま断定せず、ユーザーの承認済み範囲を超えない。情報不足は必要資料の取得で解消し、選択の議論を工程担当へ渡したり、工程中に細かくモデルを交代させたりしない。
