# 新しい主チャットからの開始文

新しい主チャットから、次の形で要求を渡す。導入作業の会話履歴は担当へ継承しない。

> `$document-as-data-tdd` このリポジトリで次の要求を実装してください。
>
> 要求：〈今回の要求〉
>
> `docs/ai-instructions/tdd-context/run.md` を入口に、
> 次の要求を工程別コンテキスト分割TDDで進めてください。
>
> Red → Green → 必要ならRefactorの順です。各工程は別コンテキストとし、
> 成果物だけを一方向に渡してください。工程間のAIレビュー・追加承認は設けません。
> Green後と実変更を伴うRefactor後は、コミットせず私に未コミット差分の確認を求め、
> 了承後にそれぞれG/Fコミットを作成してください。Refactor変更なしならFコミット不要です。
> 既存の作業ツリーと未コミット差分は保持し、分離のためにworktreeを作り直さないでください。

工程を越える未決定の外部契約が不可欠なときだけ停止する。
この開始文は製品機能、モデル、レビュー制度を追加決定するものではない。
